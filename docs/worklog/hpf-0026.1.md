## Decisions

- Read only the authenticated user's progress. Choose the latest timestamp,
  breaking ties with highest row id; null timestamps sort behind dated rows.
  Normalize unknown winning statuses to `untaught` silently, without DB repair.
- Summaries expose `frameworks` (each identified by section/family), `overall`,
  and separate `orphans`. Count catalog entries, not question coverage or rows.
  Completion is an unrounded percentage (0–100), weighted by entry count overall.
- `nextUntaught` is an entry object or null, in catalog order (supplied framework
  order overall). `noData` means no rows matched that catalog's entries, even if
  orphan rows exist; an explicit untaught row is data. Empty catalogs have 0%
  completion, `allMastered: false`, `noData: true`, and `nextUntaught: null`.

  cache key, query errors preserved, focus refresh and foreground polling.
  Scheduler, UI, writers, schema and migrations remain outside this bead.
